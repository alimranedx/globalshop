# Feature Instruction: Customer Portal

## Overview
Managed via `MarketplaceCustomerController`. Customers log in using phone/email + password on `/login` or register on `/register`.

## Features
- Marketplace product browsing & shop selection.
- Shopping cart drawer & direct Buy Now.
- Customer dashboard (`/profile`) and order list (`/profile/orders`).
- Support ticket creation for login trouble or order inquiries.
